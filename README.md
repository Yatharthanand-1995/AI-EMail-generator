
# 📧 AI Email Generator

Generate professional, friendly, or persuasive emails using OpenAI's GPT model. Built with Streamlit for a simple and clean user interface.

---

## 🚀 Features

- Choose recipient type, purpose, and tone
- Customize your message
- Instantly generate a clear, structured email
- Built using OpenAI GPT-3.5
- Easy to deploy on Streamlit Cloud

---

## 🛠️ Setup Instructions

### 1. Clone the Repo
```bash
git clone https://github.com/your-username/ai-email-generator.git
cd ai-email-generator
```

### 2. Install Requirements
```bash
pip install -r requirements.txt
```

### 3. Run the App
```bash
streamlit run app.py
```

---

## 🌐 Deploy on Streamlit Cloud

1. Upload the `app.py` and `requirements.txt` to a **public GitHub repo**
2. Go to [streamlit.io/cloud](https://streamlit.io/cloud) and sign in with GitHub
3. Click **"New App"**
4. Fill in:
   - **Repo**: `your-username/ai-email-generator`
   - **Branch**: `main`
   - **File**: `app.py`
5. Click **Deploy**

Your app will be live with a shareable URL!

---

## 🔐 API Key Handling

To use the app, you’ll need an OpenAI API key. You can get it from: [https://platform.openai.com/account/api-keys](https://platform.openai.com/account/api-keys)

**Note**: Never expose your key publicly.
